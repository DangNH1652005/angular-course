# What is Directives ?
  - is a class that allows us to add custom behavior to elements or change their appearance and structure in the DOM
# Type of Directives
  1. Component Directives 
    - Define reusable UI with their own template
    EX: @Component

  2. Attribute Directives
    - Change the appearance or behavior of an elements, component, or another directive.
    EX: ngClass, ngStyle, ngModel

# Build in Directives
  1. ngClass
  2. ngStyle
  3. ngModel

# Built-in Control Flow
  1. @Id
  2. @for
  3. @switch
    - @Case
    - @default

# Custom Directives
  - Definition: User-defined directives that allow us to add custom behavior or modify the appearance or behavior of existing elements in an Angular application
  - CLI Command: 

  ```
  ng g d directive-name
  ```

  Commom API: ElementRef, HostListener, inject()
