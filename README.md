# Angular Course

A learning project built with **Angular** to practice frontend development concepts, including components, data binding, routing, route parameters, query parameters, and navigation guards.

## 📋 Project Overview

This project is part of my Angular learning journey. It contains several pages and examples that help me understand how to build a modern web application using Angular.

## 🛠️ Technologies

* **Angular:** 22
* **TypeScript**
* **HTML5**
* **CSS3**
* **Node.js**
* **npm**

## ✨ Features

* Angular standalone components
* Component-based architecture
* Data binding
* Angular routing
* Lazy loading
* Route parameters
* Query parameters
* Navigation between pages
* `CanActivate` route guards
* `CanMatch` route guards
* `CanDeactivate` route guards
* Product list and product details pages
* Responsive page layouts

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/DangNH1652005/angular-course
```

### 2. Navigate to the project

```bash
cd angular-course
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
ng serve
```

Or:

```bash
npm start
```

### 5. Open the application

Visit:

```text
http://localhost:4200
```

## 📚 Learning Topics

This project covers the following Angular concepts:

| Topic            | Description                                    |
| ---------------- | ---------------------------------------------- |
| Components       | Building reusable UI components                |
| Data Binding     | Connecting component data to HTML              |
| Routing          | Navigating between application pages           |
| Route Parameters | Passing data through URL segments              |
| Query Parameters | Passing optional data through URLs             |
| Lazy Loading     | Loading features when needed                   |
| CanActivate      | Controlling access to routes                   |
| CanMatch         | Controlling whether routes can match           |
| CanDeactivate    | Preventing navigation when changes are unsaved |

## 🔧 Useful Commands

Create a new component:

```bash
ng generate component pages/example
```

Start the development server:

```bash
ng serve
```

Build the project:

```bash
ng build
```

Run tests:

```bash
ng test
```
